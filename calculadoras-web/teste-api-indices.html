As APIs oficiais respondem no seu navegador?

Esta página existe para responder uma única pergunta antes de a gente construir a calculadora de atualização monetária: dá para buscar os índices direto da fonte oficial, sem back-end e sem ninguém precisar digitar tabela todo mês?

Testando as fontes…

Fontes testadas

Cada linha tenta buscar os últimos valores publicados. Se aparecer um número, confira se ele bate com o índice que você conhece — é assim que a gente valida que o código da série está certo.

O que fazer com o resultado
  • Tudo verde: a calculadora pode buscar os índices sozinha, sempre atualizada, sem manutenção mensal. É o melhor cenário.
  • Tudo vermelho com "bloqueado pelo navegador": a API existe e é pública, mas não libera acesso a partir de outro site. Nesse caso a calculadora precisa ou de um back-end pequeno, ou de tabela de índices atualizada manualmente.
  • Vermelho com "sem conexão": pode ser a rede do escritório bloqueando. Vale testar de outra rede (4G do celular, por exemplo) antes de concluir.
  • Misturado: a gente usa a fonte que funcionar.

Importante: este arquivo é de uso interno, não vai para o site. Abra com dois cliques, direto do seu computador.
