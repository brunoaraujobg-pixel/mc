# Convenções deste repositório

- Cada projeto/script fica em sua própria pasta na raiz do repositório
  (ex: `organizar-documentos/`, `fronteira/`, `esocial/`, `licitacoes/`...).
  Nunca deixar scripts soltos na raiz do repositório.
- Cada pasta de projeto deve ter seu próprio `README.md` explicando o que
  o projeto faz e como usar.
- Preferir criar uma primeira versão simples e funcionando, depois evoluir
  (ver perfil/preferências do usuário para mais detalhes de arquitetura).
